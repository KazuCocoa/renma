# Renma Branding Assets

These files use the approved Renma project logo. The deep-indigo design is the
canonical initial variant.

- `renma-logo-deep-indigo.png` is the approved source image as supplied.
- `renma-logo.png` is the cropped horizontal gemstone and wordmark.
- `renma-icon.png` is the padded gemstone-only mark used in the site header.
- `favicon.png` is the small gemstone-only browser icon.

The committed derivatives were created from the approved source image without
recoloring. The original generated source is not required at runtime. Future
replacements should preserve these stable public filenames where possible.
